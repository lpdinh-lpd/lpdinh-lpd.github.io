1 Question 1: Why do we Correct for Multiple Comparisons?

A student asked me what the point of correcting for multiple comparisons was. They made a two interesting points:

  1. They are different outcomes, so, unlike the coin flip example (where the coin is the same) it doesn’t makes sense to combine them.
  2. If a manuscript presented three studies with \(t\)-tests, they don’t correct for multiple comparisons across those tests.

When we conduct all pairwise comparisons after an omnibus test like ANOVA, we are testing a single family of hypotheses to answer one overarching question (“Which of these groups are different?”). Every additional test provides another opportunity to commit a Type I error from random noise. Similar to the coin, the probability of making at least one false error across \(J\) independent tests grows exponentially: \(1 - (1 - \alpha)^J\). Note that our pairwise comparisons are not independent, so it’s slightly different.

We don’t correct for inferences across separate studies because they typically test distinct hypotheses using independent samples. Our attempt to address the multiple comparisons problem is specifically confined to the issue of increased Type I error within a single decision-making context. If we don’t, we can find ourselves in a \(p\)-hacking-like situation, where an investigator might search through many tests to find one \(p < 0.05\) (a potential false discovery), rather than making decisions to best position themselves for finding a true discovery.

Here, we will quickly demonstrate why we correct for the multiple comparisons problem when conducting several tests to answer the same question.

1.1 Part a

Complete the following steps in \(R=1000\) simulations.

  1. Simulate data for \(k=5\) samples \(n=30\) drawn from a standard Gaussian distribution.
  2. Use pairwise.t.test(..., p.adjust.method="none") to compute unadjusted pairwise \(t\)-tests and record if any comparison yields statistically discernible support for a non-zero mean.
  3. Use rstatix::tukey_hsd(...) to compute the Tukey’s HSD adjusted pairwise tests and record if any comparison yields statistically discernible support for a non-zero mean.

In the end, describe the Type I error rates.

Solution

Because data for all groups are drawn from the same distribution, there’s no mean difference between 5 groups (the null hypothesis is true).

The Type I error rate is 5 times higher in the unadjusted \(t\)-tests (\(0.286\)) than in the Tukey’s HSD adjusted pairwise tests (\(0.054\)). This means that, if we don’t correct for the multiple comparison problem, we’re much more likely to make Type I error when performing the same statistical test on the same dataset. Noted that even after correction, our Type I error rate is slightly above \(\alpha = 0.05\).

Code 
set.seed(7272)

reject1 = rep(NA, 1000)
reject2 = rep(NA, 1000)

for(i in 1:1000){
  sim = data.frame(
    g1 = rnorm (30, mean = 0, sd = 1),
    g2 = rnorm (30, mean = 0, sd = 1),
    g3 = rnorm (30, mean = 0, sd = 1),
    g4 = rnorm (30, mean = 0, sd = 1),
    g5 = rnorm (30, mean = 0, sd = 1))
  sim = sim |>
    pivot_longer(cols = everything(), names_to = "Group", values_to = "Value")

  unadjusted = pairwise.t.test(sim$Value, sim$Group, p.adjust.method = "none")
  reject1[i] = any(unadjusted$p.value < 0.05, na.rm = TRUE)
  # reject1 will be a vector of TRUE/FALSE
  hsd = rstatix::tukey_hsd(sim, formula = Value ~ Group)
  reject2[i] = any(hsd$p.adj < 0.05, na.rm = TRUE)
}

Note: The actual effect size is \(f=0.55\), but researchers usually do not know that ahead of time and defaulted to moderate, instead of specifying a large effect.

In order to detect a moderate effect size of \(f=0.25\) with 80% power, we need 40 observations per group and a total of 200 observations for 5 groups. The study was adequately powered.

2.3 Part c

In the article the researchers state:

However, the statistical power was not sufficient to allow an accurate discrimination of no to moderate stages of hepatic fibrosis (F0–F2) from severe fibrosis and cirrhosis (F3 and F4).

The European Association for the Study of the Liver (EASL) provides treatment recommendations based on these stages.

  • Stages 0-1: Treatment is deferred with regularly assessment
  • Stage 2: Treatment is justified for those in stage 2
  • Stage 3-4: Treatment is a priority for those in stages

Suppose the researcher wanted to perform a follow-up test where they want to ensure adequate power not just for the overall ANOVA \(F\)-test, but specifically to detect a pairwise differences between stages 1 and 2. Explain why the sample size computed in Part a may not be enough and use PMCMRplus::power.tukey.test() to compute a sample size that attains adequate power.

Note: The researchers would have had to do this a priori. Because we aren’t medical experts, you can use sample estimates using the original data. \[\begin{align*} n & = \text{answer from part a}\\ \mu_{\Delta} & = 0.25 \\ \sigma^2_{\text{pooled}} & = \frac{(176-1)0.85^2 + (135-1)0.84^2}{176+135-2} = 0.7152\\ \sigma_{\text{within}}= 0.77 \end{align*}\]

Solution

The sample size computed in Part a is not sufficient to detect a difference between group 1 and 2 specifically, because the power analysis for omnibus ANOVA provides us with the number of observations within each group that enables us to detect any pairwise difference 80% of the time when there is any pairwise difference (\(H_a\) is true). The probability of detecting 1 true pairwise difference among 5 groups is much higher than detecting the pairwise difference when there’s information about 2 groups only (intuitive example: if you have 5 dices, the probability of at least one of them rolling 6 is much higher than the probability of rolling 6 when you have 1 dice).

The sample size calculated in Part a only allows us to detect difference between stage 1 and 2 with \(0.07\) power. I use PMCMRplus::power.tukey.test() and repeat loop to compute a sample size that attains adequate power. We need 315 observations for each group to attain power of \(0.80\).

Code 
pwr12 = PMCMRplus::power.tukey.test(n = 40,
                                    groups = 5,
                                    delta = 0.25, #assumed mean population difference between stage 1 and 2
                                    within.var = 0.77,
                                    sig.level = 0.05)
(pwr12$power)

repeat{
  pwr12 = PMCMRplus::power.tukey.test(n = x,
                                      groups = 5,

  if(pwr12$power >= 0.80) {
    # using == 0.80 will likely never be true, because power is continuous

  }

}

2.4 Part d

How does the answer to Part c change if they wanted to have adequate power for all pairwise comparisons? Use Superpower::ANOVA_design() to set up the ANOVA set up.

Note: Use design “5b” and the following. \[\begin{align*} \boldsymbol{\mu} &= \{2.92, 3.11, 3.36, 4.04, 4.35\}\\ \sigma^2 &= \frac{(97-1)0.87^2 + (176-1)0.85^2 + (135-1)0.84^2 + (67-1)1.00^2 + (67-1)0.90^2}{97+176+135+67+67-5} = 0.80 \end{align*}\]

Compute the power of the researcher’s design (part a) using Superpower::ANOVA_power(). If the researchers were able to oversample by double, a common approach to addressing this issue, would their power be at least 80% for all pariwise comparisons?

Note: This code can take a minute. You may want to set cache: true in your R chunk yaml header. You will also see more power because the actual effect size was 0.55.

Solution

Superpower::ANOVA_power()estimates power via Monte Carlo simulation. It simulates a random dataset that has the same number of groups, sample size per group, means and SDs as the researchers assumed/expected (noted that power analysis is often conducted a priori).

It runs the ANOVA and pairwise tests on this dataset. Then, it calculates how many out of the total number of simulations (which we specify) a mean difference (between any group — \(H_a\): at least 1 mean is different) is detected. Thus, if the differences that the researchers expect does exist, the test can detect them that proportion of the times.

The researcher’s design in Part a yields 100% power to detect at least a mean difference among 5 groups, but the power to detect some pairwise comparisons are extremely low, namely the difference between stage 1 and 2 (\(16.5\%\)), stage 2 and 3 (\(22.7\%\)), and stage 4 and 5 (\(35.3\%\)). Difference between stage 1 and 3 can only be detected with approximately 60% power.

Even when sample size for each group is doubled, the powers for all pairwise comparison are not altogether beyond 80% (e.g., the power to detect difference between stage 1 and 2 is 26%).

The researchers need 331 observations per group in order to have adequate power for all pairwise comparisons.

3 Question 3: An Application

Yang et al. (2023) investigate whether low-dose nicotine can counteract age-related metabolic decline. The proposed mechanism is through \(\text{NAD}^+\), which is a chemical compound essential for metabolic energy production. The idea is that low-dose nicotine could help improve and/or maintain the recycling of \(\text{NAD}^+\) by activating the salvage enzyme NAMPT via SIRT1. This could, in turn, restore \(\text{NAD}^+\) homeostasis, which is the biological balance maintained within a cell between the production, recycling, and degradation of nicotinamide adenine dinucleotide (\(\text{NAD}^+\)).

Note: It is low-dose nicotine. Cigarette smoking delivers massive doses of nicotine along with other harmful chemicals. This is not an endorsement for smoking.

Male mice across distinct life stages – 2, 6, and 16 months – were categorized to evaluate natural, age-dependent metabolic and enzymatic shifts in two conditions.

  • Treatment: low-dose nicotine (administered in drinking water)
  • Control: no-dose placebo (administered in drinking water)

The researchers then aimed to compare treatment against control in the following samples:

  • 2 months old, control
  • 6 months old, control
  • 16 months old, control
  • 16 months old, treatment

Using PET imaging, the researchers measured age-induced inflammatory glucose hypermetabolism (\(\text{SUV}_{\text{max}}\)). They want to show that this quantity increases with age and those in the nicotine group saw levels comparable to younger mice.

3.1 Part a

State the null (\(H_0\)) and alternative (\(H_a\)) hypotheses for the omnibus test.

Solution

For the omnibus test,

\(H_0\): all 4 groups have the same $\(\text{SUV}_{\max}\) measurements (\(\mu_{2M}=\mu_{6M}=\mu_{16M}=\mu_{16MT}\))

\(H_a\): at least 1 mean is different

3.3 Part c

Perform and report the results of the omnibus test. Make sure to evaluate the conditions for using the method you choose.

Solution

The variable of interest is quantitative; the sample is presumed to be representative of the population; the sample observations are presumed to be independent; and sample size is equal across groups. From the numerical summary, we observe that groups don’t have equal variances, so we cannot perform ANOVA and will have to use Welch’s ANOVA. There’s no reason to assume normality, but this test is generally robust to normality, as long as we fulfill other conditions of use.

There is a significant difference between groups regarding glucose level (\(F_{3,3.55}=98.46, p<0.001, omega^2=0.97\)). The small sample size technically increases Type II error (the probability of failing to reject \(H_0\) when \(H_a\) is true), but in this case, we were still able to find statistically discernible support for \(H_a\) because the effect size is so large.

3.5 Part e

Write a short paragraph directly addressing the researcher’s hypothesis using your work in (a)-(d).

Solution

Games-Howell Pairwise comparisons among the untreated age groups demonstrated a statistically discernible increase in glucose hypermetabolism with age. Glucose levels were significantly higher at 16 months compared to 2 months (\(M_{diff} = 6.21, p = .007\), 95% CI [3.81, 8.60]), at 16 months compared to 6 months (\(M_{diff} = 3.47, p = .008\), 95% CI [1.56, 5.39]), and at at 6 months compared to 2 months (\(M_{diff} = 2.73, p = .012\), 95% CI [1.31, 4.15]).

Low-dose nicotine treatment at 16 months significantly reduced glucose hypermetabolism, compared to the 16-month-old control group (\(M_{diff} = 4.38, p = .043\), 95% CI [0.24, 8.51]). Notably, glucose levels in the treatment group did not differ significantly from those of the younger, untreated 2-month group (\(M_{diff} = 1.83, p = .308\), 95% CI [-3.30, 6.96]) or the 6-month group (\(M_{diff} = -0.90, p = .698\), 95% CI [-5.47, 3.67]).
